Ce que fait cet outil, et ce qu'il ne fait pas

Il signe une licence avec votre clé privée, exactement comme npm run licence sur votre ordinateur. La signature est identique octet pour octet — vérifié contre l'implémentation de Node sur votre vraie clé.

Tout se passe dans ce navigateur. Aucune donnée ne part nulle part : il n'y a pas de serveur, et la page fonctionne avion en mode avion. Votre clé ne quitte pas l'appareil.

Une licence est liée à un poste. Le code d'installation est l'empreinte de l'ordinateur du client ; la clé produite ne fonctionne que là. Un client qui change de machine redemande une clé — c'est ce qui empêche une licence de circuler entre officines.

Ce fichier n'est pas un secret ; votre clé en est un. Cette page seule ne peut rien produire. Mais si vous cochez « retenir », l'appareil devient aussi précieux que le fichier : un téléphone perdu et déverrouillé permet de fabriquer des licences gratuites pour votre logiciel.

Gardez licence-privee.pem ailleurs qu'ici. Le perdre n'invalide aucune licence déjà émise, mais interdit d'en produire de nouvelles : il faudrait changer la clé publique dans le logiciel, donc livrer une nouvelle version, donc réactiver un par un tous vos clients.
